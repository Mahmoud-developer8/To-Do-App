
# 📝 To-Do List App

A modern and responsive To-Do List application built with **HTML, CSS, and JavaScript**. Manage your daily tasks, track your progress, and keep your tasks saved using Local Storage.

## ✨ Features

- ➕ Add new tasks.
- ⌨️ Add tasks using the Enter key.
- 🚫 Prevent adding empty tasks.
- ✅ Mark tasks as completed or active.
- 🗑️ Delete individual tasks.
- 💾 Save tasks using Local Storage.
- 🔄 Restore tasks after refreshing the page.
- ⌫ Delete the last task using the Backspace key.
- 🎨 Modern dark-themed UI with smooth hover effects.
- 📱 Responsive styling for smaller screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- Event Listeners & Event Delegation
- Local Storage

## 🚀 Getting Started

Navigate to the project folder and open `index.html` in your browser.
